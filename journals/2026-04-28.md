# Session Journal — 28 April 2026 (Monday)

## Session Overview

**Goal:** Refine the homepage hero section's visual markers. The hero already had ripple/radar animations and a mesh grid with floating label markers ("Centrum Miasta", "Najlepsza Oferta 0%", "Nowy Lokal"). The user wanted to remove those text-heavy labels and replace them with something subtler and more connected to the app's identity.

**Outcome:** The three text markers were removed and replaced with five small, semi-transparent drink-category icon markers positioned at mesh node points, plus one minimal "0%" pill at the central node. The hero now visually communicates what UNI is about (non-alcoholic drinks by category) without any text labels — just tiny branded icons that float gently alongside the existing radar ripples.

---

## What Was Built

### 1. Removed Floating Text Markers — `resources/views/home.blade.php`

**What:** Deleted three `<div>` blocks (previously lines 141–156) that rendered floating label pills on the hero mesh:
- "Centrum Miasta" — a small rounded pill with primary colour
- "Najlepsza Oferta 0%" — a larger card-style badge with "Zweryfikowana Baza" subtitle
- "Nowy Lokal" — another small rounded pill

Also deleted the `float-stable` and `float-stable-delayed` CSS keyframe animations that powered their bobbing motion, since no other element uses them.

**Why:** The text markers were too heavy for the hero. They competed visually with the headline and added Polish-language copy to what should be a visual-first, brand-evoking section. The ripple animations already provide motion and life — the markers just needed to hint at what the app does, not explain it.

---

### 2. Added Drink-Category Icon Markers — `resources/views/home.blade.php`

**What:** Five new small markers placed at mesh node positions inside the hero's perspective-transformed container:

| Marker | Position | Size | Colour Source | Opacity |
|---|---|---|---|---|
| Piwo (beer) icon | bottom-left (75%, 25%) | 7×7 rounded box | `--color-drink-piwo` | 40% |
| Wino (wine) icon | upper-left (33%, 31%) | 7×7 rounded box | `--color-drink-wino` | 35% |
| "0%" pill | center (50%, 52.5%) | text pill | `--color-ok` (green) | 50% |
| Koktajle (cocktail) icon | right (58%, 81%) | 6×6 rounded box | `--color-drink-koktajle` | 30% |
| Destylaty (spirits) icon | bottom-right (80%, 62.5%) | 6×6 rounded box | `--color-drink-destylaty` | 25% |

Each icon box uses the same colour approach as the category tiles lower on the page: the drink's theme colour for the border and icon stroke, with a 10% tinted background via `color-mix()`. The SVG icons are inlined directly from `config/drinks.php` but sized down to 3–3.5px (vs the 5px used in the category tiles).

All markers have `hover:opacity-70` (or `hover:opacity-60` / `hover:opacity-80`) so they brighten subtly on mouse hover without being interactive — a polish detail.

**Why:** The drink category icons are the most distinctive visual element of UNI's identity. Placing them on the mesh creates a visual link between the hero and the category section below. The very low opacity (25–50%) keeps them atmospheric — they're texture, not content. The "0%" pill at the central node is the only text, and it's just two characters — a nod to the app's core concept without being a label.

---

### 3. New Float Animation — `resources/views/home.blade.php` (`@push('head')` styles)

**What:** Added a `float-marker` CSS keyframe animation with two variants:
- `animate-float-marker` — 7s cycle, gentle 4px vertical bob
- `animate-float-marker-delayed` — same animation, offset by 3s

The animation includes the `translate(-50%, -50%)` in its keyframes to maintain the markers' centered positioning while floating.

**Why:** The old `float-stable` animation (8s, 5px) was tied to the text markers and deleted with them. The new `float-marker` animation is slightly faster and smaller (7s, 4px) — matching the lighter visual weight of the icon markers vs the heavier text labels. The delayed variant ensures not all markers move in sync, which would look mechanical.

## Decision Register

### Drink-category icons vs abstract geometric shapes vs pin markers

- **Chosen:** Drink-category icons from `config/drinks.php` (piwo, wino, koktajle, destylaty) plus one "0%" pill.
- **Rejected option A:** Abstract geometric shapes (circles, diamonds) — would be visually clean but meaningless. They wouldn't communicate anything about what UNI does.
- **Rejected option B:** Map-pin markers — would look like a generic maps app. UNI's differentiation is drink categories, not location pins.
- **Rejected option C:** All six drink category icons — too crowded. Five markers (4 icons + 1 pill) is the right density for the mesh grid. Cydr and Musujące were omitted as the least visually distinct.
- **Why the chosen approach:** The drink icons are already part of UNI's visual language (used in category tiles, venue profiles, the multi-category promo section). Reusing them in the hero creates visual continuity. The very low opacity keeps them subordinate to the headline and ripple animations — they're a subtle brand signal, not a feature announcement.
- **Status:** Revisit when the hero design matures further. These markers are easy to swap or remove.

### Inline SVGs vs referencing `config('drinks.slug.icon')`

- **Chosen:** Inline SVG markup directly in the Blade template, copied from `config/drinks.php` but with smaller `class="w-3.5 h-3.5"` sizing.
- **Rejected:** Using `{!! config('drinks.piwo.icon') !!}` with `str_replace` to resize (as done in the category tiles section of the same page).
- **Why:** The `str_replace('class="w-5 h-5"', ...)` approach used in the category tiles is already fragile (it depends on the exact class string in the config). For the hero markers, the icons need to be even smaller (3–3.5px vs 5px), and the container divs have completely different styling. Inlining gives full control without adding another brittle `str_replace` chain. If the drink config icons change, the hero markers would need manual updating — but that's a rare event and the markers are decorative, not functional.
- **Status:** Permanent for now. If a Blade component for drink icons is ever created, these could use it instead.
